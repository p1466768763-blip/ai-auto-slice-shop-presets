# AI 自动切片_店铺预设页

千机直播切片后台的可交互静态原型，用于继续讨论店铺预设页面的设计与开发。

## 页面入口

- `index.html`：发布入口，直接进入店铺预设的「切片策略」。
- `live-slice-prototype.html`：本次会话完整原型，保留切片库、发布记录、高光切片库与店铺预设。
- `archive/live-edit-original.html`：早期独立直播精剪原型，供开发回溯。
- `document.md`：当前版本 PRD。
- `prd.html`：可直接阅读的 PRD 页面。
- `源码说明.md`：结构、状态与继续开发说明。

无需安装依赖或构建。可直接打开 HTML，或在当前目录运行 `python3 -m http.server 8000` 后访问 `http://localhost:8000/`。

## 当前可交互内容

1. 切片策略：四种生成方式、过滤项、输出数量、相似度过滤、素材复用、变速和输出比例。
2. 剪辑预设：字幕样式与位置配置及预览；其余工具保留演示面板。
3. 词库管理：热词/违禁词双池、搜索、悬停删除、独立添加、批量上传分类弹窗。
4. 两个店铺预设的切换、默认标识，以及三个 Tab 分别保存到当前浏览器本地。

这是前端原型。批量上传使用固定示例词演示，模板下载目前仅显示提示，部分业务入口仍是提示或占位面板；没有连接真实上传、识别、剪辑或后台配置服务。浏览器的本地保存只作用于当前浏览器和访问地址，不会同步其他设备。

## 发布方式

GitHub 使用 `.github/workflows/pages.yml` 部署静态页面到 Pages。Codeup 将本目录的静态页面和说明放入企业 `prd` 仓库的一个独立子目录；不在该子目录创建嵌套 Git 仓库。
